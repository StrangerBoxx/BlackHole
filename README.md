# BlackHole

Este repositorio contiene dos proyectos de juego independientes, con el mismo
concepto pero estilos visuales diferentes. Todo vive en la rama `main`.

```
BlackHole/
 ├── PortalVersion/     ← proyecto completo estilo "Portal" (lo trabajo yo)
 ├── LineArtVersion/    ← proyecto completo estilo "Line Art" (lo trabaja mi compañero)
 ├── .gitignore         ← común para ambos proyectos
 └── README.md
```

## Reglas

- Cada carpeta es un proyecto separado y autónomo. No comparten código.
- Nunca modificar archivos de la carpeta del otro proyecto.
- Solo existe la rama `main`.
- Las carpetas de proyecto no tienen su propia carpeta `.git` adentro.
- Mensajes de commit con prefijo según el proyecto:
  - `[Portal] descripción del cambio`
  - `[LineArt] descripción del cambio`
